==================== extract-xiso (how the disc image is read)

This is an xdvdfs (xbox iso) file creation/extraction utility for linux/darwin/
freebsd.

If you want to port it to your OS it shouldn't be too hard, just make sure your
fseek/ftell takes 64-bit file offsets.

I wrote this code completely from scratch today because xbiso (the one on
sourceforge) keeps seg-faulting and the code is buggy.  I got useful
documentation on the xdvdfs file system from http://xbox-linux.sourceforge.net.

I will say thanks though to the author of xbiso, it was a good start and got me
thinking!

==================== Newtown

Newtown
Copyright (c) Roger White, 1994. Released by its author into the public domain.

Newtown-Regular.ttf is the TrueType file of Newtown, as Roger White
distributed it (NEWTOW__.TTF, version 1.00, SHA-256
376d82c5b660c059c182d848d0a96da9dbe7277d7c8820f6e9a2c99b1a256c65), here
renamed. OpenCE (OpenCE-Regular.ttf) is made from it by tools/title_font.py.

The file's copyright notice ("All Rights Reserved - see .txt file for terms
for distribution and use") and the readme it was first distributed with
(personal use free, commercial use for a fee) date from 1994. Its author
later released all of his fonts into the public domain. His website,
rogersfonts.org.uk, said so from 2008 until it closed:

    "Despite what is said in the readme files associated with the fonts all
    fonts on this site are now public domain, whether used for personal use
    or for commercial purposes. All that I ask is that the source is
    acknowledged if you are using any for commercial purposes."

The statement is in the Internet Archive's copies of the site's home page,
the first of them from 24 July 2008:

    https://web.archive.org/web/20080724224405/http://www.rogersfonts.org.uk/body_index.html
    https://web.archive.org/web/20110724011202/http://www.rogersfonts.org.uk/body_index.html

and Newtown was one of the site's fonts (its samples are archived from 2004,
https://web.archive.org/web/20040909032418/http://www.rogersfonts.org.uk/assets/images/Newtown.gif).
The site says its fonts were made from the author's own hand-drawn artwork,
scanned and cleaned up.

As he asked, the source is acknowledged: OpenCE is based on Newtown by
Roger White.
